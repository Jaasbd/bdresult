# BD Result Site

Deploy (kono build step nai):
1. GitHub-e notun repo banao, ei folder-er sob file upload koro (Add file > Upload files).
2. https://vercel.com/new e giye oi repo Import koro > Deploy. Framework: "Other", settings change kora lagbe na.

Ba CLI diye: `npx vercel --prod` (ei folder-er bhitor theke).

Files: index.html (website), api/result.js (CORS proxy), vercel.json, package.json
